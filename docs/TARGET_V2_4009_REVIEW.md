## 4. 到达形状实现了，后继机制仍需谨慎归因

计划每批8请求，间距100µs，批内跨度0.700ms，平均12QPS对应批周期约666.7ms。九轮实际attempt跨度均值为0.693～0.694ms，p99及最大值为0.695～0.698ms；各轮首attempt lag均值0.058～0.059ms，全部请求的窗口lag均值0.052～0.054ms。本次没有观察到此前部分burst测试的明显批内输入拉宽，入口lag差也不能解释1～2ms策略差。

这些attempt记录在request构造/root提交之前，**不是各request真正首次入队或所有算子同时ready的时间**。真实业务是否存在这种每八请求紧邻到达的形状仍未知。peak8与24个完整批次说明所设计的请求重叠确实发生，不证明已达到持续饱和。

| seed | all普通后继迁移/16128 | all / fork / home后继wait均值 ms | all / fork / home首波wait均值 ms |
|---|---:|---:|---:|
| 420 | 5965，36.99% | 37.276 / 37.407 / 41.026 | 20.494 / 20.585 / 22.717 |
| 421 | 6179，38.31% | 37.502 / 37.705 / 41.538 | 20.507 / 20.796 / 23.037 |
| 422 | 5791，35.91% | 37.225 / 37.552 / 41.215 | 20.521 / 20.607 / 22.789 |

fork普通后继仍全部NonFork、迁移0。all额外迁移约六千个后继，只将普通后继平均wait再降低0.131/0.203/0.327ms，不能直接用这些平均值解释整request的全部收益：关键路径、不同分支尾部以及首波、join的路由均可能参与。当前没有重建逐请求关键路径。

wait起于选池、预留和诊断读取之后的提交标记，至包装callback开始；它含交接、队列及获得执行机会的等待，不是单独Folly物理队列驻留。这里的迁移是**新ready任务的选池变化**，没有搬动已入队任务，也不是OS线程迁移。

## 5. 与regular的对照说明什么

4008 regular中，借出策略peak-inflight=2、后继wait约2.63～2.70ms；本次burst8变为peak8、后继wait约37.23～37.71ms。home后继wait也从约23.74～23.94ms升至41.03～41.54ms。两个到达形态中的计算工作一致，而竞争形状明显不同，说明只看平均QPS不足以解释选池收益。

一种机制解释是：regular下单个request有较多同NUMA资源可借，burst8下多个home同时产生首波，剩余资源减少。RR六home还使每批两个NUMA请求数按5/3、4/4、3/5轮转，跨NUMA关闭会限制借用范围。这个解释符合设计和观察，但本次没有完整重建各时刻可借CPU能力，不能把它包装成已证明的唯一原因。

burst8也是人为规定的到达合同，不是从历史sched轨迹恢复的业务请求分布。不同形状已经使候选差异变化，正说明下一步要用旧trace约束可观察形态，把无法确定的业务粒度列为敏感性范围，再选取有限对照；继续无限扩展人工参数矩阵不能替代这一步。

## 7. 当前可接受结论与下一步

已得到的可靠范围是：在明确合同的六cluster部署内，两种借出在regular和burst8都优于home；初次分散收益依赖请求重叠，后继持续均衡在burst8显示约1%的均值候选收益。现有分支读写模型、任务级长短分布与联合负载诊断都已实际运行；无需再为了证明这些功能存在而重复旧轮次。

仍未建立的是**模拟与真实业务的量化对应**：真实callback的CPU/墙钟粒度、每request的ready释放时序与总CPU工作、图形状/关键路径、异步RPC占比，以及数据重用与迁移代价。这些不能仅凭旧sched的唤醒或运行区间反推出。当前算子CPU均值约8ms、规则80/4宽及2/2深、独立64KiB分支数据，都是受控设计，不是已经测得的生产画像；尤其不能由约0.876ms的线程激活驻留估计替换算子CPU分布。

下一步按[真实负载校准协议](WORKLOAD_FIDELITY_PROTOCOL.md)只读已复制的旧trace及本机产物，将可测变量、代理变量和未知项分开。真实应用不可访问，业务关联证据缺失不阻塞继续机制研究；不要求代码或重采。旧trace若继续解析，应明确解决N定义、持续时间或CPU状态的具体缺口；它不能替代缺失的request/operator标识、任务生命周期和数据访问证据。不以更多历史四池峰值拟合目标六cluster，也不继续自动生成新性能矩阵。

持续压力门控、短算子、异步RPC、较大/共享工作集、跨NUMA及尾部重复仍保留在研究范围。它们下一步的优先级和参数依据可得证据及明确标注的敏感性范围决定；本报告不声称这些实现或验收已经完成。
