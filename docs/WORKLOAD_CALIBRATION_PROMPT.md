# 给离线分析agent：旧trace补证与模拟假设边界

**本提示词的一次有界离线补证已由4010回传。结论与外部解析器限制见[4010/4011审阅](TARGET_V2_4010_4011_REVIEW.md)；当前不要求继续扫描同一旧trace。真实应用端改用[分阶段手册](PRODUCTION_AGENT_PLAYBOOK.md)或[纯prompt版](PRODUCTION_AGENT_PROMPTS_ONLY.md)。**

本提示词在**非真实业务的离线分析环境**执行。真实应用、ARM测试与开发环境之间不能直连；分析agent只使用已复制出的旧trace及本机已有派生产物。无需访问真实应用、业务源码或在线监控，不要求重新采集、部署插桩或建立网络连接。缺失业务数据不是阻塞条件。

```text
请只在当前离线分析环境完成一次有界的旧trace审计。可参考本机已有executor_demo文档 WORKLOAD_FIDELITY_PROTOCOL.md、TRACE_4005_REVIEW.md、TARGET_V2_4009_REVIEW.md；没有文档时注明，不访问远端补取。

环境与范围：
- 真实业务环境目前不可访问；不得连接该环境，不查其在线/proc、监控或源码，不要求用户重新采trace。
- 只读已复制出的trace.log、summary_exact.json、派生区间、已有分析代码和人工转述；可编写本地离线分析脚本并保存新产物，不覆盖旧结果。
- 不联网安装依赖，不启动业务或模拟压力，不修改追踪设置，不实施生产插桩。
- 原trace来自历史16QPS、4池各约128线程、未绑CPU的业务；研究目标仍为每硬件cluster一池，当前ARM测试选六cluster。不得将旧四池重分成六池，或要求恢复四池部署。

输入位置由本机已有文件决定：
- 原trace.log：<已复制到分析机的路径>
- summary_exact.json/派生区间/原分析代码：<本机目录；历史记录为/data/workspace/rank_trace/results/sched-review-2，以实际存在为准>
- 本次输出：<新的本地目录>
没有原trace但有派生产物时，分析可得部分；没有某项就标不可得，不请求生产访问。

先复用已有结果，不重复4007已完成的高桶/池间错峰表。仅当新增问题需要时，至多流式扫描旧trace一次；禁止整体read/readlines、无界DataFrame或事件列表。记录使用的文件/代码版本、绝对时间窗和耗时/内存。不能在有界资源内完成的项列缺口，不无限重试。终端报告目标80行以内，原始数据不上传。

A. 定向补证
1. 先明确N=7.8、8900次/s的对象：unique-onCPU、时间加权running、runnable+running或wake→sleep周期？打印同窗分子/分母、重复/闭合/删失/歧义数量。定义未知则不要计算Little驻留；线程周期不是算子时间。
2. 从已有区间给连续onCPU片段、wake→run、runnable切出→再运行的n/mean/p50/p95/p99。能可靠重建wake→sleep周期时，另给CPU之和/墙钟跨度和有效率；不能用运行片段冒充Folly callback。
3. 可靠状态区间内分别报告running、runnable-waiting及其和。未知区间不可补零；保留旧时钟/CPU覆盖/TID映射/丢失限制，coverage=unknown不能因本次离线解析成功而升级。
4. 若持有原1266段分析产物，核对阈值、整数计数、最终峰值分组和删失；再以当前值×已持续时间观察剩余时长。起点未知不可生成精确持续landmark；不得用未来峰值做在线输入。无法复核就明确缺失，不用均值倍数onCPU桶代替。
5. EWMA/门控若只在历史N(t)上重放，标为开环判据检查，不能声称得到迁移后的时延收益。低onCPU不等于idle；历史未绑CPU也没有16CPU硬上限。
6. 五种sched事件没有request/operator/ready标记时，executor请求到达、每request CPU、算子粒度、DAG、RPC、工作集均标“不可由本数据识别”；不搜索生产环境补齐，不把waking当任务提交。

B. 对后续模拟的有界建议
1. 列“历史trace实测现象”“用户描述但未核实”“目前未知”三类，注明统计对象与窗口。
2. 给最多3个值得验证的形态，如短集中、持续多波、共同竞争；说明证据与未知项，不从同一调度输出反演唯一的任务输入。
3. 未知任务粒度、ready节奏、RPC及数据足迹用明确标注的敏感性范围研究，不编造生产分布，不把0.85ms线程周期直接设成算子预算。
4. 后续实验在独立ARM测试环境保持每cluster一池，比较策略对这些不确定性的稳定性；不要求真实业务访问或重新采集后才能继续。
5. 明确无法确认生产收益和默认最优参数，但不要把这个外推限制当成本轮工程/机制研究无法推进。
```

此提示词与持续性审计有重合时合并执行，不重复扫描。后续生产接入条件见协议的后置章节，不属于本次agent任务。
