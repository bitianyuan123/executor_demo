# 阶段3：最小后续计划

当前计划已根据“12 QPS、初始30ms内80+任务、随后持续计算、其他池也有负载”的业务补充更新。

请执行[微突发与目标池接纳验证指南](REQUEST_WAVE_GUIDE.md)：一次短校准，随后同一冻结负载下home、源阈值0.8、源0.8加目标接纳0.5三组，各一次。

它替代此前B80/T128的cluster/none四组额外计划，不叠加执行。仍保留[已有ARM结果报告](ARM_3003_METRIC_POLICY_REPORT.md)，但不将不同输入的结果混合比较。

本轮不扫描阈值，不重复三次，不增加线程数或亲和性矩阵；不修改DAG/Folly工程。CPU利用率只用于旁路观测，不进入路由算法。合成负载预算、未确定的业务参数、时延口径和终端收集方式都在新指南中明确列出。
