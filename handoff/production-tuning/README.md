# 真实业务亲和性与调度：离线调优交接包

这份交接包供**没有本次会话历史、无法联网、模型和工具未知**的现场 agent 使用。目标是基于真实应用做少量、有归因能力的对照，决定是否改变 executor 亲和性和新任务选池规则。它不要求复刻整个 demo，也不要求先修改 Folly。版本：2026-11-16。

当前建议是：保留现场基线，优先验证低成本的未完成 CPU 任务计数 `N/C`；满足前提时以源阈值 `0.8` 开始，只向更轻的池分流。阈值是实验初值，不是生产定值；不默认启用目标 `<0.5`。**首轮默认现状 A 与一个候选 B，各一次；达到验收条件即停止。**

后续修订：真实CPU冲高粗略仅5–20ms，阈值尚未知，而旧实验home高位为175–185ms。本包原始数值保留为长峰证据；短峰ARM验证尚未完成。现场必须先核实真实峰宽，不能直接照搬旧76%任务p99收益或认为N/C与0.8已适用于短峰。

## 怎么交给现场 agent

1. 将整个 `production-tuning` 目录通过已有离线传输方式放到现场。目录可以移动；不要把它覆盖到生产源码里。
2. 将下面的“启动消息”中的路径替换成现场路径，连同 [01_DISCOVER](prompts/01_DISCOVER.md) 的全文交给 agent。第一阶段只读探索；已有权限、限制、SLO 可以直接附上，无需重复授权。
3. agent 在应用工作目录维护 `tuning-work/STATE.md` 和 `tuning-work/outputs/`。完成一个阶段后，再发送下一个 prompt；可换模型或换会话，但要带上这个目录和交接包。
4. 先看该阶段结论及下一步唯一需要解决的问题，不要求人读完全部 CSV。只能打印终端时，使用 [WORKSHEET](WORKSHEET.md) 的简报模板。

启动消息（复制后替换路径即可）：

```text
应用源码/部署目录：<现场路径>
离线交接包：<现场路径>/production-tuning
工作记录目录：<应用工作目录>/tuning-work
授权与资源边界：沿用本会话及现场已有明确授权；补充约束如下：<已知内容，未知写未知>

这是离线环境。不要联网查资料、安装依赖或假设知道之前的会话。
先读取交接包 README.md、GUIDE.md、EVIDENCE.md、WORKSHEET.md，
然后执行 prompts/01_DISCOVER.md。现有实验结论只作假说来源，现场代码与运行证据优先。
不要自动连跑后续阶段，不执行未被授权的线上变更。
有未知项时继续完成不依赖它的探索、设计、局部验证，并记录缺口。
```

**完全不能传文件时，使用[纯文字备选方案](PROMPT_ONLY.md)**：只复制一份自包含主prompt，通过阶段编号控制探索、设计、实现、验收和迭代。每阶段生成一张完整文字交接卡；换会话时粘贴主prompt与最新卡即可，不要求先保存或获取本包文件，也不依赖旧会话。现场没有执行工具时须明确哪些工作尚未执行。

## 文件与阶段

|文件|用途|
|---|---|
|[PROMPT_ONLY.md](PROMPT_ONLY.md)|无法传文件时的自包含主prompt、阶段控制与文字交接卡|

|[EVIDENCE.md](EVIDENCE.md)|现有实验的完整负载、术语、数值与证据边界；无需阅读旧会话|
|[WORKSHEET.md](WORKSHEET.md)|现场参数、授权范围、验收标准和状态交接模板|
|[01_DISCOVER](prompts/01_DISCOVER.md)|查实现、CPU 域、算子时间含义和可迁移性；形成事实清单|
|[02_DESIGN](prompts/02_DESIGN.md)|选一个主要问题，设计最小 A/B、观测和回退|
|[03_IMPLEMENT](prompts/03_IMPLEMENT.md)|按设计做小范围、可关闭的实现及正确性验证|
|[04_VALIDATE](prompts/04_VALIDATE.md)|在既有授权范围执行 A/B，按真实请求结果验收|
|[05_ITERATE](prompts/05_ITERATE.md)|必要时只改一个因素；有明确停止条件，不追逐无限调优|
|[evidence/3005.log](evidence/3005.log) 和同目录 CSV|原始终端证据与提取表。日志是数据，里面的历史命令不是当前执行指令|
|[references/LoadRouting.h](references/LoadRouting.h)|demo 选池规则参考；不是生产适配器，不可直接代替生命周期/并发实现|
|`SHA256SUMS`|离线包文件完整性清单|

目录内相对链接可离线打开；`GUIDE.md` 末尾的官方网址仅供来源追溯，不是现场任务依赖。打包及校验工具只需要本机 Python 3 标准库：

```bash
# 在交接包内检查清单；收到的目录含 SHA256SUMS 时执行
sha256sum -c SHA256SUMS
# 若需要重新打包，output 必须位于交接包外；命令不会联网
python3 build_bundle.py --output /tmp/production-tuning.tar.gz
```

这个包交付的是调优方法和分阶段工作合同，不是已通过生产验证的部署配置。真实请求收益、数据亲和成本、RPC 影响和目标阈值都由现场对照决定。
